# 故障分类与已确认的坑

## 定位顺序

1. 收集首条错误正文、buildId、动作、场景、地图/坐标、日志源位置。只看到abort或<table>不能定位最初故障。
2. 确认日志对应当前产物。按对应build的来源映射/真实行号读取小段代码；新build的同一行号可能完全不同。
3. 查源事件/资源/绑定和公共调用链。先提出可检验根因，再改最小位置。
4. 做有意义的定向检查，验证出错路径，必要时重建一次/重载；正确区分源码、模拟器、官方。
5. 写入对应类别，不混写成“项目还有Bug”。

## 分类标准与记录路径

| 类别 | 判断 | 修改/记录 |
| --- | --- | --- |
| 构建器 Bug | 合法输入下，共用编译器、打包器、宿主接口或通用运行时违反契约 | 公共src/tools + 公共回归；构建器报错经验.md |
| 工程转换 Bug | 特定源工程的插件/事件脚本/资源身份/配置被错误适配 | 对应adapter、extensions、projects；工程转换报错经验.md，注明gameId和源位置 |
| 原工程问题 | 相同现象在原生源工程可复现 | 记录原生证据，源修改需在任务授权内；不能未经验证甩锅原工程 |
| 环境/工具问题 | 错误路径、旧实例、测试fixture、命令引号等 | 标工具问题，不假装已改运行时代码 |
| 待定位 | 证据不够 | 记录现象与下一步，不能先按文件名猜类别 |

归档位置使用本次资料表中的错误记录目录或本地工作区明确约定。没有约定时建议当前工程内的文档目录；不沿用技能作者的个人目录。历史 `报错经验.md` 若存在则保留原记录，新问题分类写；一个故障只保留一个持续更新条目。

记录至少包含：类别、gameId或公共范围、构建、原始错误、源/模块位置、已确认事实与推断、修复、实际检查、导出结果、未验证边界。不能用最终堆栈所在模块简单判定归属。

## 常见故障与正确修复方向

| 现象 | 已遇到的根因/排查方向 | 不应采用的处理 |
| --- | --- | --- |
| OnStart→nativeId→fail | 官方文档id与模拟器Id不同；用公共已知契约选择和稳定ID缓存 | 把模拟器API当官方、编造ID、用userdata地址混作稳定身份 |
| copy/dense→__index | 只枚举复制宿主标准库，漏掉math.huge等延迟成员 | 关闭数值/数组校验、假定源数据坏了 |
| abort又报__index | 错误处理调用模块环境不提供的print，遮住原错 | 只留一条<table>、清理异常覆盖第一条错误 |
| fontSize integer expected | 比例换算后浮点数直接写原生整数属性 | 每处随意取值，缺统一出口 |
| 字号超出限制 | 把minimumFontSize设为1或突破目标范围 | 无限缩小字号补救错误布局 |
| 有窗口没字/设置换行 | 模板内容、颜色/层级、字号、行高、文本框宽高或最小字号不匹配 | 一概说缺文本框、只看HTML而不测原生文字 |
| 长正文丢字/超过1000字 | 把UTF-8字节当字符数，未分页或写入过長文本 | 直接截掉正文、不留翻页入口 |
| 长按只走一步 | 只响应KeyDown瞬间，没用按住状态推动后续步 | 依赖系统键盘自动重复 |
| UGC下面3D也在动 | 宿主容器没屏蔽按键事件穿透 | 在每个子图元重复监听拦截 |
| 按钮无音效 | 只发信号但无接收播放，或没有真实客户端audioId | 声称发信号等于已播放、抄旧样例音效ID |
| BGM只停不恢复 | 缺cue/position恢复接线，或接收端忽略play.position | 凭空增加未约定resume参数 |
| 同一旧行号反复报错 | 日志、磁盘Lua和正在运行实例不是同一build | 未核对就反复改当前相同行号 |
| 地图控件峰值/移动卡顿 | 先创建后回收、大块过量加载、全图扫描、逐子改位置或大量原生查询 | 简单提高6000保护上限、全地图同时常驻 |
| 回收一次卡很久 | 销毁大父树级联删除，或对子逐个隐藏 | 将一次Destroy计作1而忽略后代 |
| Lua execution took too long | 有限批量事件也可能有巨量重复复制/属性视图；核对调用次数 | 直接断言无限循环、改超时阈值、跳过源脚本 |
| 资源到处是同一种图形 | 同名变体合并、图块类别猜测、默认头像/敌人兜底 | 加更多名称/颜色启发式猜测 |
| 人物转向像只动眼睛 | 四方向造型没有实际独立结构 | 只翻眼睛/局部装饰冒充侧面 |
| 背景条纹/山像阶梯 | 用大量横条或像素块模拟简单大形状 | 无上限提高采样密度和控件数量 |
| E_PRIMITIVE_ART | 实际引用未有明确图元或模板、资源键/帧不匹配 | 画一个临时默认对象让构建“通过” |
| E_UI_TEMPLATE_* | 未登记/错误子树数量/超过400原子克隆/目标模板变化 | 手填假count或跳过结构检查 |
| E_UI_PROFILE/E_*UNSUPPORTED | 当前版本或插件能力未实现 | 写假sourceVersion、删插件或假返回成功 |
| E_BUNDLE_LIMIT | 单Lua超过20,000,000字节或相关输入预算 | 偷拆多个运行Lua、不告诉用户丢了资产 |

## 两个实际分类样例

### 公共问题：运行控件身份

导出4f245版模拟器成功，官方OnStart失败；官方文档是id，模拟器是Id。修公共ui_lifecycle，首次选文档字段、兼容已确认模拟器差异，然后缓存；稳定原生ID解决GetChildren/GetClientUIControl返回新包装的问题。用两个宿主形态检查，不能让mock和错误实现使用同一个错拼写。

### 转换问题：Visu全队学技能

源 `data/CommonEvents.json $[20].list[0]` 是有限批量学习，旧适配对163项技能×8队员执行1304次昂贵事务/视图。修Visu接入调用通用learnSkills，集合合并先校验后提交；不生成事件用不到的stats。定向测试比较原标量与批量最终状态，检查幂等、无效ID回滚和未选角色不变。模拟器实际显示学习完成；不能把本地结果写成官方耗时已达标。

## 工具陷阱

- PowerShell不支持Bash花括号路径展开；优先rg枚举真实路径。
- 中文路径/输出显式UTF-8，Python可用 `-X utf8`；大JSON审计确需提高离线读取项数时只调整该审计输入，不顺手取消生产限制。
- PowerShell中文弯引号也可能被识别为引号；多行文字用单引号here-string或文件传递，避免字符串插值破坏内容。
- 当前工作区若没有.git，只能说未提供Git diff；不要伪造提交/干净状态。
- 测试fixture遗漏依赖、使用不存在的控件名、按钮已禁用等都是先核对测试前提的理由，不是降低生产约束的理由。
